# bsdfs_lean

Lean4 code for the `bsdfs` algorithm with proofs of its main properties/theorems:

- soundness: every output is a simple s-t path with at most k edges,
- completeness: every such path is output exactly once,
- worst-case delay: every interval (o_τ, o_{τ+1}] costs at most 2k(n + m) steps,
- amortized delay: the τ-th observable event (start, output, termination)
  happens after at most τ(k+2)(n+m) steps.

The four main theorems were machine-checked for path mode, on the Lean model of the algorithm.

All Lean code was generated by Anthropic Claude Opus 5.5 (at Max level) within less than
half a day from the following sources
- preprint https://arxiv.org/abs/2607.14745 containing all lemmas, theorems, and proofs,
- several additional notes, and
- a Python reference implementation (https://github.com/FrankBau/bsdfs).

Lean version 4.34.1 (https://lean-lang.org/) was used for automated proof-checking.

If you mutate the algorithm in `bsdfs\Bsdfs\BsdfsExec.lean`, e.g. replace
`  let mut sd := k + 1` by `  let mut sd := k`; you will get errors.
In this case: Some required targets logged failures: Bsdfs.Complete.
