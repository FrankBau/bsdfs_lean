# bsdfs_lean

Lean4 code for the `bsdfs` algorithm with proofs of its main properties:
soundness, completeness, worst-case delay, amortized delay.

The four main claims were machine-checked for path mode, on the Lean model of the algorithm.

All Lean code was generated by Anthropic Claude Opus 5.5 (at Max level) within less than
half a day from the following sources
- preprint https://arxiv.org/abs/2607.14745 containing all claims and proofs,
- several additional notes, and
- a Python reference implementation (https://github.com/FrankBau/bsdfs).

Lean version 4.34.1 (https://lean-lang.org/) was used for automated proof-checking.
